# 🎮 Jogo de Adivinhação de Números

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![Status](https://img.shields.io/badge/Status-Concluído-success?style=for-the-badge)
![Licença](https://img.shields.io/badge/Licença-MIT-blue?style=for-the-badge)

Um jogo simples desenvolvido em **Java** onde o jogador deve adivinhar um número aleatório gerado pelo sistema em até **5 tentativas**.

---

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais da programação em Java, como:

- Variáveis
- Estruturas condicionais (`if`, `else if`, `else`)
- Estruturas de repetição (`while`)
- Entrada de dados com `Scanner`
- Geração de números aleatórios com `Random`
- Controle de fluxo
- Lógica de programação

---

## 🚀 Funcionalidades

- 🎲 Geração automática de um número aleatório.
- 🔢 Recebimento de palpites do usuário.
- 📈 Dicas para ajudar o jogador:
  - Chute mais alto.
  - Chute mais baixo.
- ⏳ Limite de 5 tentativas.
- 🏆 Mensagem de vitória ao acertar.
- ❌ Mensagem de derrota ao esgotar as tentativas.

## ▶️ Como Executar

### Clone o repositório

```bash
git clone https://github.com/seu-usuario/JogoAdivinharNumero.git
```

### Entre na pasta do projeto

```bash
cd JogoAdivinharNumero
```

### Compile o projeto

```bash
javac Main.java
```

### Execute

```bash
java Main
```

---

## 🎯 Exemplo de Execução

```text
Tente adivinhar um número de 0 a 100:

50
Está perto, Chuta mais alto...

75
Está longe, Chuta mais baixo...

63
Parabéns, Você acertou o número! com 3 Tentativas.
```
